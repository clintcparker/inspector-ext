# inspector-ext Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Firefox MV3 extension that adds a presumptive-officer qualification panel to the Inspector's district dashboard on `member.freemason.org`, plus "Add as presumptive…" controls on the member page and the district members list.

**Architecture:** Thin content scripts render and collect input. A background event page owns a pure `service` that fetches the slow site (queue of at most 2 concurrent requests, 60 s timeout, 1 retry), parses the HTML with pure parsers, caches in `storage.local` (stale-while-revalidate, TTL 7 days), and keeps the hand-built roster. Content scripts redraw when `storage.onChanged` fires.

**Tech Stack:** Plain JavaScript (ES modules in the background, classic scripts for the content scripts), `web-ext` lint and build, Vitest with `happy-dom` for unit tests, `puppeteer-core` over WebDriver BiDi for end-to-end tests.

**Spec:** `docs/superpowers/specs/2026-10-28-inspector-ext-design.md`. **Notes:** `docs/design-notes.md`. **Rules for tooling:** `CLAUDE.md`.

**Refinements to the spec, already applied to spec §4.3–4.4:**
- Updates reach the tabs through `storage.onChanged` rather than pushed `memberUpdated` messages, so there is no tab tracking.
- The background builds the whole view model, including the rule results. The panel only draws it.
- The background reads the member-page sidebar itself, through `memberInfo`.
- The e2e test has no slow endpoint. Timeouts and retries are unit-tested in `queue.test.js`.

## Global Constraints

- Manifest V3. The background is `background.scripts` with `"type": "module"`, not a service worker.
- `browser_specific_settings.gecko.id` = `inspector-ext@clintparker.com`, `gecko.strict_min_version` = `"140.0"`, `gecko_android.strict_min_version` = `"142.0"`, `gecko.data_collection_permissions` = `{"required":["none"]}`.
- `host_permissions` = `["https://member.freemason.org/*"]` and `permissions` = `["storage"]` only. The test-only variant adds `http://localhost/*`; it is generated by `test/e2e.mjs` and never shipped.
- `npm run lint` must pass with warnings treated as errors. Never use `innerHTML`, `alert`, `confirm` or `prompt`; build DOM with `createElement` and `textContent`.
- Every log line starts `[inspector-ext]`. Logs never contain member names, member IDs, emails or cookies, only counts and request kinds.
- **Never commit or copy anything from `research/site-capture/`.** All fixtures are synthetic: made-up names, IDs and dates.
- Dates inside the extension are ISO `YYYY-MM-DD` strings, compared with `<` and `>`.
- The office codes are exactly `"WM" | "SW" | "JW" | "SD"`.
- Rule constants are verbatim from the spec:
  - LMCP courses: `"Hall Association Management Exam"`, `"Lodge Administration Exam"`, `"Member Experience Exam"`, `"Finance Exam"`.
  - Completion: `"Lodge Management Certification Program"` (educational) or `"Lodge Management Certification Completion Award"` (awards).
  - MM proficiency: `"Proficiency - MM"`.
  - Ritual: `"<OFFICE> Officer Qualification"`.
  - Window: 5 years back from today. Expiring: expiry before `<termYear>-01-01` or within 90 days of today.
- **Commits:** the repo has no commits yet. Before the first commit step, ask the user to confirm committing. After that, commit at the end of each task as written.

```js
async function probe(path) {
  const started = Date.now();
  try {
    const res = await fetch(`https://member.freemason.org${path}`, { credentials: "include" });
    const text = await res.text();
    const doc = new DOMParser().parseFromString(text, "text/html");
    return {
      path: norm(path),
      status: res.status,
      finalPath: norm(new URL(res.url).pathname),
      ms: Date.now() - started,
      signInForm: Boolean(doc.querySelector('input[name="user[password]"]')),

      listTable: Boolean(doc.querySelector("table.list-table")),
      bodyTextLength: doc.body?.textContent.trim().length ?? 0,
    };
  } catch (e) {
    return { path: norm(path), error: String(e) };
  }
}

browser.runtime.onMessage.addListener(async (msg) => {
  if (msg?.type !== "probe") return;
  const out = [];
```

```js
// Dates are ISO "YYYY-MM-DD" strings so they compare with < and >.

export function parseUsDate(text) {
  const m = /^\s*(\d{1,2})\/(\d{1,2})\/(\d{4})\s*$/.exec(text ?? "");
  if (!m) return null;
  return `${m[3]}-${m[1].padStart(2, "0")}-${m[2].padStart(2, "0")}`;
}

export function todayIso(now = new Date()) {
  const p = (n) => String(n).padStart(2, "0");
  return `${now.getFullYear()}-${p(now.getMonth() + 1)}-${p(now.getDate())}`;
}

function shift(iso, { years = 0, days = 0 }) {
  const [y, m, d] = iso.split("-").map(Number);
  return new Date(Date.UTC(y + years, m - 1, d + days)).toISOString().slice(0, 10);
}

export const addYears = (iso, n) => shift(iso, { years: n });
export const addDays = (iso, n) => shift(iso, { days: n });
```

```js
export function route(site, path, state = {}) {
  if (state.signedOut && path !== "/users/sign_in") return { status: 302, location: "/users/sign_in" };
  if (state.override?.has(path)) return { status: 200, body: state.override.get(path) };
  const lodge = (id) => site.lodges.find((l) => l.id === id);
  let m;
  if (path === "/users/sign_in") return { status: 200, body: signInPage() };
  if ((m = /^\/districts\/(\d+)$/.exec(path)) && Number(m[1]) === site.district) return { status: 200, body: districtPage({ number: site.district, lodges: site.lodges }) };
  if (path === "/districts/district_members") {
    return { status: 200, body: membersList(Object.entries(site.members).map(([id, x]) => {
      const l = lodge(x.lodgeId);
      return { memberId: Number(id), name: `${x.last}, ${x.first}`, memberNumber: 900000 + Number(id), status: "Master Mason", lodge: `${l.name} No.${l.number}` };
    })) };
  }
  if ((m = /^\/ous\/(\d+)\/ou_officers$/.exec(path)) && site.officers[m[1]]) return { status: 200, body: officersFragment(site.officers[m[1]]) };
  if ((m = /^\/mems\/(\d+)$/.exec(path)) && site.members[m[1]]) return { status: 200, body: memberPage(site.members[m[1]]) };
  if ((m = /^\/mems\/(\d+)\/sidebar_memberships$/.exec(path)) && site.members[m[1]]) return { status: 200, body: sidebarMemberships([lodge(site.members[m[1]].lodgeId)]) };
  if ((m = /^\/members\/(\d+)\/(proficiency_events|educational_events|awards|history)$/.exec(path)) && site.members[m[1]]) {
    const events = site.members[m[1]].events[TAB_KEYS[m[2]]];
    if (!events.length && m[2] !== "history") return { status: 200, body: emptyEventsTab("Awards") };
    return { status: 200, body: eventsTab(TAB_HEADINGS[m[2]], events) };
  }
  return { status: 404, body: "<!DOCTYPE html><title>Not found</title>" };
}

// A fetch() stand-in for unit tests that follows redirects like the browser does.
export function siteFetch(site, origin = "https://member.freemason.org") {
  const state = { signedOut: false, requests: [], override: new Map() };
  const fetchImpl = async (url) => {
    let path = new URL(url).pathname;
    for (let hops = 0; hops < 5; hops++) {
      state.requests.push(path);
      const r = route(site, path, state);
      if (r.status === 302) { path = r.location; continue; }
      return { ok: r.status < 400, status: r.status, url: origin + path, text: async () => r.body };
    }
    throw new Error("redirect loop");
  };
  return { fetchImpl, state };
}
```

```js
export function lodgeNumber(text) {
  const m = /No\.\s*(\d+)/.exec(text ?? "");
  return m ? Number(m[1]) : null;

function fromLink(a) {
  const text = a.textContent.trim();
  return { id: idFromHref(a), name: text.replace(/\s*No\.\s*\d+\s*$/, ""), number: lodgeNumber(text) };

export function parseDistrictLodges(html) {
  const links = toDoc(html).querySelectorAll('.district-sidebar-link a[href^="/lodges/"]');

// The /mems/{id}/sidebar_memberships fragment. No memberships is a valid answer.
export function parseMemberLodges(html) {

    if (lodge.id != null && !seen.has(lodge.id)) seen.set(lodge.id, lodge);
```

```js
// Qualification rules for presumptive officers (spec §2.1).
import { addDays, addYears } from "./dates.js";

export const OFFICES = ["WM", "SW", "JW", "SD"];
export const LMCP_COURSES = ["Hall Association Management Exam", "Lodge Administration Exam", "Member Experience Exam", "Finance Exam"];
const HAM = LMCP_COURSES[0];
const COMPLETION_EDUCATIONAL = "Lodge Management Certification Program";
const COMPLETION_AWARD = "Lodge Management Certification Completion Award";
const MM_PROFICIENCY = "Proficiency - MM";
const WINDOW_YEARS = 5;
const WARN_DAYS = 90;
const NEEDED = { WM: 4, SW: 3, JW: 1 };

const latest = (events = [], type) => events.filter((e) => e.type === type).map((e) => e.date).sort().at(-1) ?? null;
const dated = (date) => (date ? { status: "met", date } : { status: "missing" });
const expiry = (date) => addYears(date, WINDOW_YEARS);

function lmcp(office, events, today) {
  if (office === "SD") return { status: "na" };
  const live = (date) => Boolean(date) && expiry(date) > today;
  const courses = LMCP_COURSES.map((type) => ({ type, date: latest(events.educational, type) })).filter((c) => live(c.date));
  const ham = courses.find((c) => c.type === HAM);
  const others = courses.filter((c) => c !== ham).map((c) => expiry(c.date)).sort().reverse();
  const all = courses.map((c) => expiry(c.date)).sort();
  const needed = NEEDED[office];
  let met;
  let expires = null;
  if (office === "WM") {
    met = courses.length;
    if (met === needed) expires = all[0];
  } else if (office === "SW") {
    met = (ham ? 1 : 0) + Math.min(2, others.length);
    if (met === needed) expires = [expiry(ham.date), others[1]].sort()[0];
  } else {
    met = Math.min(1, courses.length);
    if (met === needed) expires = all.at(-1);
  }
  const completionDate = [latest(events.educational, COMPLETION_EDUCATIONAL), latest(events.awards, COMPLETION_AWARD)].filter(Boolean).sort().at(-1);
  const completion = live(completionDate) ? completionDate : null;
  if (completion && (!expires || expiry(completion) > expires)) {
    met = needed;
    expires = expiry(completion);
  }
  return { status: expires ? "met" : "missing", met, needed, expires, courses, completion };
}

export function evaluate(office, events, { termYear, today }) {
  const cells = {
    mm: dated(latest(events.history, MM_PROFICIENCY)),
    ritual: dated(latest(events.proficiency, `${office} Officer Qualification`)),
    lmcp: lmcp(office, events, today),
  };
  const l = cells.lmcp;
  if (l.status === "met" && (l.expires < `${termYear}-01-01` || l.expires <= addDays(today, WARN_DAYS))) l.status = "expiring";
  return cells;
}
```

```js
// Fetches pages from the (slow) site: at most `concurrency` at once, a timeout
// per attempt, and one retry for timeouts, network errors and 5xx.
export function createQueue({ fetchImpl, concurrency = 2, timeoutMs = 60_000, retryDelayMs = 5_000, sleep = (ms) => new Promise((r) => setTimeout(r, ms)) }) {
  const waiting = [];
  const inflight = new Map();
  let active = 0;

  async function attempt(url) {
    const ctl = new AbortController();
    const timer = setTimeout(() => ctl.abort(), timeoutMs);
    try {
      const res = await fetchImpl(url, { credentials: "include", signal: ctl.signal });
      const text = await res.text();
      if (!res.ok) return { ok: false, error: "http", status: res.status, retry: res.status >= 500 };
      return { ok: true, status: res.status, url: res.url || url, text };
    } catch {
      return { ok: false, error: ctl.signal.aborted ? "timeout" : "network", retry: true };
    } finally {
      clearTimeout(timer);
    }
  }

  async function run(url) {
    let r = await attempt(url);
    if (!r.ok && r.retry) {
      await sleep(retryDelayMs);
      r = await attempt(url);
    }
    const { retry, ...result } = r;
    return result;
  }

  function pump() {
    while (active < concurrency && waiting.length) {
      const { url, resolve } = waiting.shift();
      active++;
      run(url).then(resolve).finally(() => {
        active--;
        pump();
      });
    }
  }

  return {
    get(url) {
      if (!inflight.has(url)) {
        const p = new Promise((resolve) => {
          waiting.push({ url, resolve });
          pump();
        }).finally(() => inflight.delete(url));
        inflight.set(url, p);
      }
      return inflight.get(url);
    },
    get size() {
      return active + waiting.length;
    },
  };
}
```

```js
// In-memory stand-in for browser.storage.local (get/set with structured clones).
export function memoryStorage(initial = {}) {
  const data = structuredClone(initial);
  return {
    data,
    async get(keys) {
      const list = keys == null ? Object.keys(data) : [keys].flat();
      return Object.fromEntries(list.filter((k) => k in data).map((k) => [k, structuredClone(data[k])]));
    },
    async set(obj) {
      Object.assign(data, structuredClone(obj));
    },
  };
}
```

```js
// Turns stored data into what the dashboard panel draws (spec §5).
import { memberKey } from "./cache.js";
import { entriesFor } from "./roster.js";
import { OFFICES, evaluate } from "./rules.js";

const CURRENT = { "Worshipful Master": "WM", "Senior Warden": "SW", "Junior Warden": "JW", Secretary: "Sec" };

export function buildView({ lodges, roster, members, officers, termYear, today, pending, signedOut }) {
  const stamps = [];
  const stamp = (entry) => {
    if (entry?.fetchedAt) stamps.push(entry.fetchedAt);
  };
  const entries = entriesFor(roster, termYear);
  const view = {
    termYear,
    signedOut,
    pending: pending.size,
    lodges: lodges.map((lodge) => {
      const off = officers[lodge.id];
      stamp(off);
      return {
        id: lodge.id,
        name: lodge.name,
        number: lodge.number,
        current: off?.officers
          ? off.officers.filter((o) => CURRENT[o.office]).map((o) => ({ label: CURRENT[o.office], name: o.name, memberId: o.memberId }))
          : null,
        currentError: off?.error ?? null,
        rows: OFFICES.map((office) => ({
          office,
          candidates: entries
            .filter((e) => e.lodgeId === lodge.id && e.office === office)
            .map((e) => {
              const m = members[e.memberId];
              stamp(m);
              return {
                memberId: e.memberId,
                name: e.name,
                loading: pending.has(memberKey(e.memberId)) || !m,
                error: m?.error ?? null,
                cells: m?.events ? evaluate(office, m.events, { termYear, today }) : null,
              };
            }),
        })),
      };
    }),
  };
  view.updatedAt = stamps.length ? Math.min(...stamps) : null;
  return view;
}
```

```js
// Background logic, free of browser.* so it can be unit-tested. Owns the
// roster, the fetch queue and the cache (spec §4).
import { isSignInResponse } from "../parse/auth.js";
import { parseMemberEvents } from "../parse/events.js";
import { parseDistrictLodges, parseMemberLodges } from "../parse/lodges.js";
import { parseMembersList } from "../parse/members-list.js";
import { parseLodgeOfficers } from "../parse/officers.js";
import { isFresh, memberKey, officersKey } from "./cache.js";
import { todayIso } from "./dates.js";
import { createQueue } from "./queue.js";
import { addEntry, entriesFor, removeEntry } from "./roster.js";
import { OFFICES } from "./rules.js";
import { buildView } from "./view.js";

const TABS = [
  { key: "proficiency", path: "proficiency_events" },
  { key: "educational", path: "educational_events" },
  { key: "awards", path: "awards" },
  { key: "history", path: "history" },
];

export function createService({ storage, fetchImpl, now = () => Date.now(), log = () => {}, queueOptions = {} }) {
  const queue = createQueue({ fetchImpl, ...queueOptions });
  const pending = new Set();
  const running = new Set();
  let signedOut = false;

  async function load() {
    const { lodges = [], roster = {}, settings = {} } = await storage.get(["lodges", "roster", "settings"]);
    const s = { ttlDays: 7, ...settings };
    return { lodges, roster, settings: s, termYear: s.termYear ?? new Date(now()).getFullYear() + 1 };
  }

  const touch = () => storage.set({ status: { pending: pending.size, signedOut, at: now() } });

  function schedule(p) {
    const tracked = p.catch((e) => log(`refresh failed: ${e?.name ?? "error"}`)).finally(() => running.delete(tracked));
    running.add(tracked);
  }

  async function fetchPage(origin, path) {
    const r = await queue.get(origin + path);
    if (!r.ok) {
      log(`fetch failed kind=${r.error}${r.status ? ` status=${r.status}` : ""}`);
      return { error: "fetch" };
    }
    if (isSignInResponse(r.url, r.text)) {
      signedOut = true;
      return { error: "signedOut" };
    }
    signedOut = false;
    return { text: r.text };
  }

  // Runs one refresh; `work` resolves to { entry } or { error: "fetch"|"signedOut" }.
  async function refresh(key, work) {
    if (pending.has(key)) return;
    pending.add(key);
    try {
      await touch();
      const result = await work();
      if (result.error === "signedOut") return;
      const { [key]: old } = await storage.get(key);
      await storage.set({ [key]: result.error ? { ...old, error: result.error } : result.entry });
    } finally {
      pending.delete(key);
      await touch();
    }
  }

  const refreshOfficers = (origin, lodgeId) =>
    refresh(officersKey(lodgeId), async () => {
      const page = await fetchPage(origin, `/ous/${lodgeId}/ou_officers`);
      if (page.error) return page;
      const parsed = parseLodgeOfficers(page.text);
      return { entry: parsed.ok ? { fetchedAt: now(), officers: parsed.data } : { fetchedAt: now(), error: "layout" } };
    });

  const refreshMember = (origin, memberId) =>
    refresh(memberKey(memberId), async () => {
      const pages = await Promise.all(TABS.map((t) => fetchPage(origin, `/members/${memberId}/${t.path}`)));
      const failed = pages.find((p) => p.error === "signedOut") ?? pages.find((p) => p.error);
      if (failed) return failed;
      const events = {};
      for (const [i, t] of TABS.entries()) {
        const parsed = parseMemberEvents(pages[i].text);
        if (!parsed.ok) return { entry: { fetchedAt: now(), error: "layout" } };
        events[t.key] = parsed.data;
      }
      return { entry: { fetchedAt: now(), events } };
    });

  async function refreshStale(origin, force, scope = "all") {
    const { lodges, roster, settings, termYear } = await load();
    const inLodge = (lodgeId) => scope === "all" || scope.lodgeId === lodgeId;
    const lodgeIds = lodges.map((l) => l.id).filter(inLodge);
    const memberIds = [...new Set(entriesFor(roster, termYear)
      .filter((e) => (scope.memberId ? e.memberId === scope.memberId : inLodge(e.lodgeId)))
      .map((e) => e.memberId))];
    const keys = [...lodgeIds.map(officersKey), ...memberIds.map(memberKey)];
    const cached = keys.length ? await storage.get(keys) : {};
    const stale = (key) => force || !isFresh(cached[key], now(), settings.ttlDays);
    for (const id of lodgeIds) if (stale(officersKey(id))) schedule(refreshOfficers(origin, id));
    for (const id of memberIds) if (stale(memberKey(id))) schedule(refreshMember(origin, id));
  }

  async function view() {
    const { lodges, roster, termYear } = await load();
    const ids = [...new Set(entriesFor(roster, termYear).map((e) => e.memberId))];
    const keys = [...ids.map(memberKey), ...lodges.map((l) => officersKey(l.id))];
    const got = keys.length ? await storage.get(keys) : {};
    return buildView({
      lodges,
      roster,
      termYear,
      members: Object.fromEntries(ids.map((id) => [id, got[memberKey(id)]])),
      officers: Object.fromEntries(lodges.map((l) => [l.id, got[officersKey(l.id)]])),
      today: todayIso(new Date(now())),
      pending,
      signedOut,
    });
  }

  const forMember = (roster, termYear, memberId) => entriesFor(roster, termYear).filter((e) => e.memberId === memberId);

  async function handle(msg, origin) {
    switch (msg.type) {
      case "loadDistrict": {
        const parsed = parseDistrictLodges(msg.html);
        if (!parsed.ok) return { error: "layout" };
        await storage.set({ lodges: parsed.data });
        await refreshStale(origin, false);
        return view();
      }
      case "view":
        return view();
      case "setTermYear": {
        const { settings } = await load();
        await storage.set({ settings: { ...settings, termYear: Number(msg.termYear) } });
        await refreshStale(origin, false);
        return view();
      }
      case "refresh":
        await refreshStale(origin, true, msg.scope ?? "all");
        return view();
      case "addCandidate": {
        if (!OFFICES.includes(msg.office) || !Number.isInteger(msg.memberId) || !Number.isInteger(msg.lodgeId)) return { error: "bad-request" };
        const { roster, settings } = await load();
        const entry = { lodgeId: msg.lodgeId, office: msg.office, memberId: msg.memberId, name: String(msg.name ?? ""), addedAt: now() };
        const next = addEntry(roster, msg.termYear, entry);
        await storage.set({ roster: next });
        const { [memberKey(msg.memberId)]: cached } = await storage.get(memberKey(msg.memberId));
        if (!isFresh(cached, now(), settings.ttlDays)) schedule(refreshMember(origin, msg.memberId));
        return { entries: forMember(next, msg.termYear, msg.memberId) };
      }
      case "removeCandidate": {
        const { roster } = await load();
        await storage.set({ roster: removeEntry(roster, msg.termYear, msg) });
        return view();
      }
      case "memberInfo": {
        const { lodges, roster, termYear } = await load();
        const page = await fetchPage(origin, `/mems/${msg.memberId}/sidebar_memberships`);
        const mine = page.text ? parseMemberLodges(page.text).data : [];
        const matches = lodges.filter((l) => mine.some((m) => m.id === l.id));
        return { termYear, lodges: matches.length ? matches : lodges, entries: forMember(roster, termYear, msg.memberId) };
      }
      case "listRows": {
        const parsed = parseMembersList(msg.html);
        if (!parsed.ok) return { error: "layout" };
        const { lodges, roster, termYear } = await load();
        const rows = parsed.data.map((r) => {
          if (!r) return null;
          const matches = lodges.filter((l) => l.number === r.lodgeNumber);
          return { memberId: r.memberId, name: r.name, lodges: matches.length === 1 ? matches : lodges, entries: forMember(roster, termYear, r.memberId) };
        });
        return { termYear, rows };
      }
      case "ping":
        return { pending: pending.size };
      default:
        return { error: "unknown-message" };
    }
  }

  async function idle() {
    while (running.size) await Promise.all([...running]);
  }

  return { handle, idle };
}
```

```js
    return box;
  }

  function candidateRow(view, lodge, office, c, first) {
    return el("tr", { class: "ie-candidate", dataset: { office, memberId: c.memberId } },
      el("td", {}, first ? office : ""),
      el("td", {},
        el("a", { href: `/mems/${c.memberId}` }, c.name),
        el("button", { type: "button", class: c.error ? "ie-retry" : "ie-refresh-member", title: c.error ? "Retry" : "Refresh this member", onclick: () => send({ type: "refresh", scope: { memberId: c.memberId } }).then(render) }, "⟳")),
      ...cells(c),
      el("td", {}, removeControl(view.termYear, lodge.id, office, c.memberId)));
  }

  function currentLine(lodge) {
    if (!lodge.current) return [lodge.currentError ? ERRORS[lodge.currentError] : "… loading"];
    return lodge.current.flatMap((o, i) => [i ? " · " : "", `${o.label} `, o.memberId ? el("a", { href: `/mems/${o.memberId}` }, o.name) : "vacant"]);
  }

  function lodgeSection(view, lodge) {
    const body = lodge.rows.flatMap((row) =>
      row.candidates.length
        ? row.candidates.map((c, i) => candidateRow(view, lodge, row.office, c, i === 0))
        : [el("tr", { class: "ie-empty", dataset: { office: row.office } }, el("td", {}, row.office), el("td", { colspan: "5" }, "(none yet: add from a member's page or the members list)"))]);
    return el("section", { class: "ie-lodge", dataset: { lodgeId: lodge.id } },
      el("h6", {},
        el("span", { class: "ie-lodge-name" }, `${lodge.name} No. ${lodge.number}`),
        el("button", { type: "button", class: "ie-refresh-lodge", title: "Refresh this lodge", onclick: () => send({ type: "refresh", scope: { lodgeId: lodge.id } }).then(render) }, "⟳")),
      el("p", { class: "ie-current" }, "Current: ", ...currentLine(lodge)),
      el("table", { class: "info-table ie-table" },
        el("thead", {}, el("tr", {}, ...["Office", "Candidate", "MM prof.", "Ritual qual.", "LMCP", ""].map((h) => el("th", {}, h)))),
        el("tbody", {}, ...body)));
  }

  function termSelect(termYear) {
    const y = new Date().getFullYear();
    const years = [...new Set([y, y + 1, y + 2, termYear])].sort();
    const select = el("select", { class: "ie-term", "aria-label": "Term year", onchange: (e) => send({ type: "setTermYear", termYear: Number(e.target.value) }).then(render) },
      ...years.map((v) => el("option", { value: v }, v)));
    select.value = String(termYear);
    return select;
  }

  let keepAlive;
  function render(view) {
    if (!view || view.error) return;
    root.replaceChildren(el("div", {},
      el("div", { class: "ie-head" },
        el("h5", {}, "Inspector: Presumptive Officers · Term"),
        termSelect(view.termYear),
        el("span", { class: "ie-updated" }, view.pending ? `updating… (${view.pending})` : `updated ${ago(view.updatedAt)}`),
        el("button", { type: "button", class: "ie-refresh", onclick: () => send({ type: "refresh", scope: "all" }).then(render) }, "⟳ Refresh")),
      view.signedOut ? el("p", { class: "ie-banner" }, "Sign in to member.freemason.org to refresh. Showing saved data.") : null,
      ...view.lodges.map((lodge) => lodgeSection(view, lodge))));
    // Firefox unloads idle event pages; a message every 20 s keeps the
    // background alive while it is still fetching.
    clearInterval(keepAlive);
    if (view.pending) keepAlive = setInterval(() => send({ type: "ping" }), 20_000);
  }

  send({ type: "loadDistrict", html: document.documentElement.outerHTML }).then((view) => {
    if (view?.error) root.replaceChildren(el("p", { class: "ie-banner" }, "Inspector panel: site layout changed, can't find the district's lodges."));
    else render(view);
  });
  onDataChanged(() => send({ type: "view" }).then(render));
})();
```
